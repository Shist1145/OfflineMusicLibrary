# 网易云歌单导入：匹配规则与排错

OfflineMusicLibrary 的网易云功能是“把公开歌单结构映射到本地文件”，不是在线音乐下载器。导入成功表示找到了可信的本地媒体文件；远端存在但本地没有的歌曲会留在未匹配报告中。

## 导入流程

1. 从链接或数字 ID 提取网易云歌单 ID。
2. 请求歌单基本信息、声明歌曲数量和 `trackIds`。
3. 合并歌单响应中已经附带的歌曲详情。
4. 对缺少详情的 ID 以 100 首为一组请求。
5. 100 首请求部分或全部失败时，对仍未解析的 ID 以 25 首为一组重试。
6. 保留所有已经取得的歌曲 ID；详情仍缺失的 ID 进入 `UnresolvedTrackIds`，不会被伪装成普通“本地缺歌”。
7. 对有详情的远端歌曲与本地索引进行全局一对一匹配。
8. 只有远端 ID 和详情足够完整时，才允许删除旧歌单中已经确认不再属于远端歌单的条目。

## 匹配优先级

### 1. 可信云 ID

本地歌曲曾经成功对应某个网易云 ID 时，会优先保留该关系。但云 ID 不是无条件正确：如果远端普通版与本地文件明显是伴奏版，旧关系会被判定为历史错误并重新分配。

### 2. 版本类型必须一致

普通演唱版不会与带有以下标记的无人声文件互相匹配：

- `Off Vocal`、`Off Vo`、`Vocal-less`
- `Instrumental`、`Inst.`、`Karaoke`
- `Backing Track`、`Minus One`、`No Vocals`
- `伴奏`、`伴奏版`、`纯音乐`、`純音樂`、`純音楽`
- `无人声`、`無人聲`、`无主唱`、`無主唱`、`去人声`
- `オフボーカル`、`オフ・ヴォーカル`、`ボーカルなし`、`歌なし`、`インスト`

标记可以在标题或文件名中。版本判断发生在标题清理之前，因此不会因为删除“Instrumental”噪声而把两个版本重新混在一起。

### 3. 歌名、艺人、专辑和时长

- 歌名会做 Unicode 兼容归一化、括号/序号/常见视频噪声处理和编辑距离比较。
- `feat.artist` 与 `feat. artist` 都可以被识别为附加艺人后缀。
- 艺人支持中英文分隔符、`feat`、`ft`、`with` 等组合。
- 专辑相同会提高可信度，但不会单独压过明显错误的版本类型。
- 两端都有时长时，接近时长会加分；明显不同的版本不会因为标题相似而轻易抢占候选。
- 同一首既有 NCM 又有普通可播放文件时，会在分数接近的情况下优先普通文件。

### 4. 全局一对一分配

导入不会从上到下贪心地拿走“当前看起来最好”的文件。系统先收集每首远端歌曲的候选，再通过增广分配把受约束最强的歌曲优先安排，保证一个本地文件只对应本次歌单中的一个远端条目。

这解决了典型问题：

```text
远端 A：Moonlight          候选：本地 1、本地 2
远端 B：Moonlight Sonata  候选：本地 1
```

贪心算法可能让 A 抢走本地 1，导致 B 失败；全局分配会把本地 1 留给 B，再让 A 使用本地 2。

## 导入报告怎么看

| 字段 | 含义 |
| --- | --- |
| 网易云声明歌曲 | 歌单元数据中的总数 |
| 完整歌曲 ID | 实际取得并去重的 `trackIds` 数量 |
| 已读取歌曲详情 | 已取得歌名、艺人、专辑等详情的 ID 数量 |
| 详情暂未返回 | 有 ID 但本次接口未返回详情；不会授权清理旧歌单 |
| 云 ID 精确匹配 | 由可信历史 ID 找到的本地文件 |
| 名称/艺人/专辑匹配 | 由当前元数据评分找到的本地文件 |
| 修正历史错误云 ID | 从错误文件移走并重新写入的 ID 关系数量 |
| 已有详情但仍未匹配 | 远端信息可用，但当前曲库没有足够可信的唯一候选 |

## 为什么仍可能少于远端数量

- 本地确实没有该歌曲文件。
- 本地只有同曲目的另一种版本，例如 Live、Remix、伴奏或不同长度剪辑。
- 一个本地文件对应网易云中的多个重复发行 ID；为了保证一对一，本次只会使用一次。
- 文件标签、文件名和远端信息都过少，系统选择不做高风险猜测。
- 歌曲详情仍未返回；下次导入会继续尝试。
- 本地文件是受保护 NCM，且没有可正常播放的对应文件。

## 大歌单导入建议

- 保持音乐硬盘在线，并确认新增文件已经复制完成。
- 第一次从旧版升级时，导入前同步会为旧索引补齐文件戳，并只读取真正新增的文件。
- 如果刚刚批量修改了标签，使用“重新识别社团”执行一次强制元数据刷新。
- 不要因为一次详情暂缺就删除并重建歌单；1.6.2 会保留原条目，稍后重新导入即可。
- 导入过程中可以用刷新/取消按钮停止同步；取消不会保存半成品曲库。

## 开发者只读实况审计

确定性测试不访问网络。需要审计真实公开歌单时，可以显式运行：

```powershell
dotnet run --project tests/NetEasePlaylistChecks/NetEasePlaylistChecks.csproj -c Release -- `
  --live "$env:LOCALAPPDATA\OfflineMusicLibrary\library-v2.json" "歌单ID"
```

该模式读取状态文件并访问网易云公开接口，但不会调用 `SaveAsync`。输出中可能包含本地路径，分享前必须脱敏。
